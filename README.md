## 🚀 GitHub Pages 배포 방법 (3단계)

이 프로젝트는 별도의 빌드 과정(Webpack, Vite 등)이 필요 없는 순수 바닐라 웹 기술로 구성되어 있어, GitHub에 올리는 즉시 호스팅할 수 있습니다.

### 1단계: GitHub에서 새 저장소 생성
1. [GitHub](https://github.com/) 로그인 후 우측 상단의 `+` 버튼 → **New repository** 클릭.
2. Repository name 입력 (예: `talesweaver-guide`).
3. **Public** 선택 후 `Create repository` 클릭.

### 2단계: 로컬 저장소 연결 및 푸시
프로젝트 폴더에서 터미널을 열고 아래 명령어를 순서대로 실행합니다:

```bash
# Git 초기화 (최초 1회)
git init

# 모든 분리된 파일 추가 및 커밋
git add .
git commit -m "feat: Modularize web companion guide for TalesWeaver with CSS/JS split"

# GitHub 원격 저장소 연결 (본인의 GitHub 주소로 변경)
git remote add origin https://github.com/<본인의-GitHub-아이디>/<저장소-이름>.git

# main 브랜치로 푸시
git branch -M main
git push -u origin main
```

### 3단계: GitHub Pages 활성화
1. GitHub 저장소 페이지의 상단 탭에서 **Settings** 클릭.
2. 좌측 메뉴의 Code and automation 섹션에서 **Pages** 클릭.
3. **Build and deployment** 항목:
   - **Source**: `Deploy from a branch` 선택
   - **Branch**: `main` 선택 / 폴더는 `/ (root)` 선택
4. **Save** 버튼 클릭.
5. 약 1~2분 뒤 페이지 상단에 배포 URL(`https://<아이디>.github.io/<저장소이름>/`)이 생성되며, 전 세계 어디서든 브라우저로 접속 가능합니다!
