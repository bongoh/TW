## ✨ 핵심 기능 안내

### 1. 🧪 54종 실전 도핑 · 버프 대시보드 & 스탯 시뮬레이터
- **공식 가이드(공지 131192) 기반 54종 버프 총망라**: 기본 도핑, 상시 유지, 물약, 추가 도핑, 경험치, 레어 도핑 6개 카테고리 분류.
- **중복 불가(충돌) 자동 잠금 시스템**: 중복 불가능한 아이템(예: 클럽 Type E-2 ↔ 스승의 증표 ↔ 따뜻한 에오스) 선택 시 시각적 비활성화 및 경고 토스트 팝업.
- **노버프 / 실전 버프 실시간 스탯 판정**: 마을 노버프 수치 입력 후 원하는 버프를 체크하면 마방·명중·속성이 실시간으로 자동 합산되어 목표 던전 진입 여부를 판정.

### 2. 🎯 7대 핵심 던전 실시간 진입 적합도 매트릭스
- 신조의 둥지(일반), 어비스(일반/헬), 오방 헬, 로카고스(이클립스), 이클립스 고난도, 오방 어비스 등 7개 던전의 통과 여부를 한눈에 비교.
- 카드 클릭 한 번으로 목표 던전 즉시 전환 및 최소 수치 대비 마진(+/-) 실시간 산출.

### 3. ⚔️ 주간 핵심 보스 & 던전 도감 (SVG 전술도 수록)
- **어벤던로드 보스 [타이탄] 반사 실드**: 눈알/칼 보라색 변신 후 반사 실드 발동 시 **공격 즉시 원콤 즉사**! 실드가 꺼질 때까지 완전 대기 기믹 및 4단계 파훼 SVG 전술도 제공.
- **도박 NPC 100% 무시 팁**: 보스 처치 후 시드를 탕진시키는 도박 NPC 차단 안내.
- **에토스 4방향 돌진**: TWChatOverlay 알림음 대응 및 사각지대 이동 전술도.
- **어비스 2사도 반사 쉴드**: 딜 중지 타이밍 및 힐 장판 유지 요령.
- **특화 던전 공략**: 수르트(프라바 방어전 1인), 닉스(망각의 카타콤 석화 해제), 머큐리얼 4보스/루미너스/어둠의 카사드, 시뮬레이션 발굴지(커프 강화).

## 🚀 GitHub Pages 배포 방법 (3단계)

이 프로젝트는 별도의 빌드 과정(Webpack, Vite 등)이 필요 없는 순수 바닐라 웹 기술로 구성되어 있어, GitHub에 올리는 즉시 호스팅할 수 있습니다.

### 1단계: GitHub에서 새 저장소 생성
1. [GitHub](https://github.com/) 로그인 후 우측 상단의 `+` 버튼 → **New repository** 클릭.
2. Repository name 입력 (예: `talesweaver-guide`).
3. **Public** 선택 후 `Create repository` 클릭.

### 2단계: 로컬 저장소 연결 및 푸시
프로젝트 폴더에서 터미널을 열고 아래 명령어를 순서대로 실행합니다:

```bash
# Git 초기화 (최초 1회)
git init

# 모든 분리된 파일 추가 및 커밋
git add .
git commit -m "feat: Modularize web companion guide for TalesWeaver with CSS/JS split"

# GitHub 원격 저장소 연결 (본인의 GitHub 주소로 변경)
git remote add origin https://github.com/<본인의-GitHub-아이디>/<저장소-이름>.git

# main 브랜치로 푸시
git branch -M main
git push -u origin main
```

### 3단계: GitHub Pages 활성화
1. GitHub 저장소 페이지의 상단 탭에서 **Settings** 클릭.
2. 좌측 메뉴의 Code and automation 섹션에서 **Pages** 클릭.
3. **Build and deployment** 항목:
   - **Source**: `Deploy from a branch` 선택
   - **Branch**: `main` 선택 / 폴더는 `/ (root)` 선택
4. **Save** 버튼 클릭.
5. 약 1~2분 뒤 페이지 상단에 배포 URL(`https://<아이디>.github.io/<저장소이름>/`)이 생성되며, 전 세계 어디서든 브라우저로 접속 가능합니다!
